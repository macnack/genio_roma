# Prebuilt Images

To get started quickly, it is recommend to use the prebuilt Yocto image. This is the fastest and easiest way to bring up the hardware without setting up a full build environment.

## Download the Image

There are multiple prebuilt images with various extensions enabled. Each file name indicates the extensions enabled in the image. Here is the [list of all the available image configurations](https://developer.grinn-global.com/boards/grinn-genio-700-sbc/software/yocto/getting-started/image-configurations).

## Unpack the Image

Unpack the downloaded archive and go directly to the [Flash Prerequisites](https://developer.grinn-global.com/boards/grinn-genio-700-sbc/software/yocto/getting-started/flash-prerequisites) section to flash the image to the board.
